One emoji that stands for an AI agent: **🐝** — the honeybee. A tireless
worker that builds the hive one small job at a time. Instantly readable,
unmistakable, and not a robot or a smiley.

## What it does

`main.py` (pure Python standard library, deterministic) writes exactly one
emoji — 🐝, U+1F41D HONEYBEE, with no trailing newline — to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # 🐝
```

Every run produces the same 4 bytes (`f0 9f 90 9d`).
